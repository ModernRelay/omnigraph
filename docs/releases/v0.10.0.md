# OmniGraph v0.10.0 (cancelled development record)

No v0.10.0 release was cut from this development line. The former contents of
this page described the RFC-026 streaming experiment and internal manifest
formats v7-v19. That experiment was rejected before release; those formats are
abandoned, are not an upgrade ladder, and are refused by the current v6 binary.

Current bounded graph ingestion reuses ordinary actor-aware Load, publishes one
graph commit, and acknowledges only after manifest visibility. The decision,
retained evidence, and compatibility posture are recorded in
[Streaming ingestion after RFC-026](../dev/wal-removal.md). The rejected design
itself remains available as [RFC-026](../rfcs/0026-memwal-streaming-ingest.md).
