- `omnigraph-server` can serve one standalone graph to clients of the same account on loopback. `AppState::local` opens it read-only or read-write behind a generated bearer token and a generated policy for one actor, `start_local` installs the server's shutdown lifecycle on a listener the caller bound, so a signal after it returns stops the server gracefully, `LocalServing::serve` then serves and reports an uncertain outcome instead of exiting (`serve_local` does both), and `install_log_subscriber` applies the server's log filter to another writer. See [public embedding APIs][local-server-embedding].
