- A graph opened on a captured storage destination, through a CLI target or a
  cluster's server, now sends every storage request there. Writes that check
  an edge cardinality, branch creates and deletes, three-way merges, reads by
  commit id, historical traversals and change-feed pages built some of their
  clients from the process's provider environment, so an ambient endpoint
  setting such as `AWS_ENDPOINT_URL` could send those requests elsewhere or
  fail them. See [operator targets][bound-reads-targets].
