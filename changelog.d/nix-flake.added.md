- A Nix flake builds `omnigraph`, `omnigraph-server` and
  `omnigraph-azure-admission` from source on Linux x86_64 and arm64 and macOS
  arm64, with the release archives' toolchain, packages and features:
  `nix build github:ModernRelay/omnigraph`. See the [install guide][nix].
