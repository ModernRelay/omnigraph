- `omnigraph-bench` can measure read-only GQT workloads against an externally provisioned `omnigraph-server`, with served query and traversal scenarios. A run needs a typed deployment receipt and a graph provisioned for the scenario's fixture recipe. Served records separate declared server evidence from observed client evidence, preserve unavailable server counters as absent, and remain ineligible for performance claims. See the [served acquisition guide][served-read-benchmarks-guide].
