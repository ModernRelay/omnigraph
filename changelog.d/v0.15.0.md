In local LDBC SF30 runs, CSV bulk loads take under half the 0.14 time.
Reads on an open graph do not wait for its writes. Diffs and merges read only
the data that changed. MCP exposes every graph operation except byte
streams. Policy alone decides what an agent can run. An S3 cluster server stops
writing at its lease deadline. This release changes `@card`
checks, MCP flags, organization commands, saved plans and a Rust error
type. Read the upgrade actions before you upgrade. Graph storage and the HTTP
contract stay the same. Existing graphs open without a rebuild.

## Why these changes

Each change closes a gap between what Omnigraph declared and what it did. A
`@card` minimum held or failed depending on how a write reached the same
graph. MCP flags hid tools that the same credential could already call over
HTTP, so policy is now the only gate. Organization roles came from provider
defaults and local grants; you now name them. A `U64` above `i64::MAX` was
refused, and an in-doubt publication named no commit to check.

## Highlights

### CSV bulk load: SF30 in under half the 0.14 time

Pipelined bulk load: an overwrite `load csv` streams from the source object to
the Lance writers. Each parse partition range-reads its own 8 MiB pieces,
checks uniqueness in a shared hash table and probes integer-keyed edge
endpoints as rows arrive; full fragments are written while the next rows
parse. The removal scan runs only when a retained-edge check needs it, and a
refused load leaves no fragment. In the pull requests' LDBC SNB SF30 runs (31
overwrite statements into a fresh graph, release builds, an Apple silicon
workstation on local disk), the load fell from 261 s at 0.14.0 to 87–110 s.
#1141, #1147, #1158, #1178

### Reads no longer wait for a write

Read-copy-update: an open graph's branch state is a copy-on-write value behind
an atomic pointer. A read loads it without a lock; a publish, refresh or
schema pass works on a copy and installs it with one compare-and-swap. A
multi-table write validates and commits its tables concurrently: two serial
round trips at commit instead of two per table. The first read after another
process commits refreshes `__manifest` in 11 or 12 storage calls instead of
18 to 20 (DST cost ledger, in-memory store). #1228, #1270, #1230

### Merges at 1,024 commits: 4,168 storage requests down to 54

Change discovery from fragment metadata: Lance keeps each row's stable row id
and the version that last wrote it in its fragment's metadata. A diff across
several commits of one history pairs rows by id and reads only those whose
stamps differ, so its data read is flat in table size; ten updated rows in a
100,000-row type cost 277 data reads and 6.9 MB before. A merge reads
candidates only from each side's changed fragments, which the exact-id
primary key makes safe. After 1,024 one-row commits, a fast-forward merge
sends 54 storage requests instead of 4,168 and a three-way merge 135 instead
of 3,216 (GQT `--measure`, DST in-memory store). Diverged heads and Blob
tables keep the full comparison. #1201, #1220, #1229

### MCP: every graph operation, gated by policy

Tool parity: `/mcp` has a tool for every graph operation that is not a byte
stream, including `diff`, `branches_diff`, `commits_publish` and stored
mutations. Each tool calls its HTTP route's handler under the same Cedar
action, so the server lists every tool and the caller's policy decides what
runs. `query` takes GQ source or a stored read's `name`. A ranked read
returns a `ranking` object: the search, its score order, whether it was
exhaustive, and the score columns. #1139, #1207, #1130

### S3 clusters: no write after the lease deadline

Deadline fencing: the storage scope holds the owner's lease deadline, and
admission, each multipart part and each poll of a request check it before
sending. After a process pause, whichever task resumes first sends nothing
past the deadline, and a restarted server never takes the lock from an owner
that still heartbeats. A conditional control-object write on S3 or Azure
whose answer was lost is re-issued unchanged and read back; equal bytes mean
it landed. #1221, #1176
