- `omnigraph mcp --target NAME [--graph ID]` speaks MCP over stdio for an agent that starts its tools as commands, relaying each line as one request to the target's `/mcp`: a direct target through its local server, which the bridge reuses or hosts until its stdin closes, and a server target with its credential owner's stored token, which never reaches the agent's configuration. Requests are relayed concurrently, at most 32 at a time, and answered as they complete; `initialize` and notifications keep their order, and `notifications/cancelled` drops the named request. The bridge is bound to one graph, filling `graph` when a call omits it and refusing another, and lists and admits only the tools the server annotates read-only. After a 401 or a refused connection it resolves the target once more, once for requests lost together; failing again, it answers every pending request and exits 1 with `mcp_target_lost`, a new CLI error code. See [agents over stdio][cli-mcp-bridge].
