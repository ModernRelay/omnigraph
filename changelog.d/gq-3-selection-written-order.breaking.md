- A selection, `(a | b)` or `*`, reads each member in the direction its end types fix and is refused with `T82` only when no member points along the written order: `$c * $p` is refused where every edge between the two types is declared `Person -> Company`, and its fix swaps the ends. See [traversal][gq-3-selection-guide].
