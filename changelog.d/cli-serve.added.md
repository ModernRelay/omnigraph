- `omnigraph serve` serves one direct target, a standalone graph or a cluster root, on `127.0.0.1` to clients of the same account: read-only, as the `--as` or `operator.actor` actor, behind a generated bearer token; `--write` refuses until a write whose outcome is unknown no longer stops the server. With `--json` it prints one ready line once it handles signals, and it keeps an owner-only record a client attaches by reading. There is one live local server per destination; `--reuse` attaches to it, and refuses one started by a CLI with another HTTP contract or other storage formats. Refusals carry a `code` and an `outcome`, and a machine whose host identifier cannot be read refuses to keep records. Only requests naming its loopback address, with no `Origin`, reach it. `target list` and `target show` name each target's live local servers, and `version --json` reports `protocols.serve` and `protocols.local_server_record`. See [local servers][cli-serve].
