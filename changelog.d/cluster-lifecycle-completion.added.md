- Cluster apply supports policy grants/revocations and rebinding, embedding-provider changes, and external-Blob rules on existing graphs without restarting the server. Plan performs the same effect-free checks as apply without taking writer admission, and unrelated unavailable graphs do not block independent changes. Removing a graph declaration uses the same deployment and physically deletes its managed root and retained history after affected work drains. Adoption, missing-root recreation and repair overrides are unsupported. See [cluster operations][cluster-lifecycle-completion].
